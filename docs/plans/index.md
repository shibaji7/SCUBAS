# Plans for the planned capabilities

Four capabilities are on the [roadmap](../roadmap.md). None is built. Each page below says what the capability is for, what SCUBAS already has that it will build on,
what the literature says (and whether it was read in full or only found), and what is still open. They are plans to be edited by the maintainers, not designs; a number or a
method that appears here as a question is a question.

| Capability | Plan | Stub (raises `NotImplementedYetError`) |
|---|---|---|
| Uncertainty quantification | [Uncertainty](uncertainty.md) | `scubas.future.uncertainty.propagation` |
| Automatic segmenter | [Segmenter](segmenter.md) | `scubas.future.segmentation.auto_segmenter` |
| Auroral electrojet design | [Electrojet](electrojet.md) | `scubas.future.sources.electrojet` |
| FDTD/FEM for coastal effects | [Coastal effects](coastal.md) | `scubas.future.coastal.numerical` |
